Solving inequalities

Inequalities are solved like equations, with one extra rule about negative numbers.

1 Learn2 See3 Try4 Play5 Test6 Challenge

Learn

An inequality uses <, >, ≤ or ≥. Its solution is a whole range of numbers, shown on a number line. An open circle means the end number is not included (< or >); a closed circle means it is (≤ or ≥).

Solving

Use the same steps as for equations. 2x + 1 > 7 becomes 2x > 6, so x > 3.

The one extra rule

When you multiply or divide by a negative number, flip the sign. For example −3x < 12 becomes x > −4. Check: x = 0 works, since −3(0) = 0 < 12.

Check your answer by testing one number inside your range and one outside it.

See three worked examples

Solve 4x − 5 ≤ 11.
  1. Add 5: 4x ≤ 16.
  2. Divide by 4 (positive, so no flip): x ≤ 4.

Answer: x ≤ 4, closed circle at 4, shaded left

Solve 7 − 2x > 1.
  1. Subtract 7: −2x > −6.
  2. Divide by −2 and flip: x < 3.
  3. Check x = 0: 7 − 0 = 7 > 1. ✓

Answer: x < 3

What is the smallest whole number with 3x + 2 > 20?
  1. Subtract 2: 3x > 18. Divide by 3: x > 6.
  2. x must be bigger than 6, so the smallest whole number is 7.

Answer: 7
