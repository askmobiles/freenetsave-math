Variables on both sides

When x appears on both sides, move all the x terms to one side and all the numbers to the other.

1 Learn2 See3 Try4 Play5 Test6 Challenge

Learn

In 5x + 3 = 2x + 15, there are x's on both sides. Subtract 2x from both sides to collect them on the left: 3x + 3 = 15. Now it is a two-step equation: 3x = 12, so x = 4.

Which side?

Move the smaller x term, so the x's left over are positive. It is not wrong to do it the other way; it just avoids negatives.

Special cases

  • If the x's cancel and you get a false statement (like 3 = 7), there is no solution.
  • If you get a true statement (like 5 = 5), every number is a solution.

Expand brackets first, then collect: 2(x + 4) = 5x − 1 becomes 2x + 8 = 5x − 1.

See three worked examples

Solve 7x − 4 = 3x + 12.
  1. Subtract 3x: 4x − 4 = 12.
  2. Add 4: 4x = 16.
  3. Divide by 4: x = 4.

Answer: x = 4

Solve 2(x + 4) = 5x − 1.
  1. Expand: 2x + 8 = 5x − 1.
  2. Subtract 2x: 8 = 3x − 1.
  3. Add 1: 9 = 3x, so x = 3.

Answer: x = 3

Solve 3(x − 2) = 3x + 1.
  1. Expand: 3x − 6 = 3x + 1.
  2. Subtract 3x: −6 = 1, which is false.

Answer: no solution
