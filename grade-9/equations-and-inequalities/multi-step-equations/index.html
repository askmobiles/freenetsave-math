Solving multi-step equations

An equation is a balance. Whatever you do to one side, do to the other, until the variable is alone.

1 Learn2 See3 Try4 Play5 Test6 Challenge

Learn

To solve an equation means to find the value of the variable that makes both sides equal.

The plan

  1. Expand any brackets (or divide both sides by the number outside, if it divides evenly).
  2. Collect like terms on each side.
  3. Undo adding or subtracting.
  4. Undo multiplying or dividing.
  5. Check by putting the answer back into the original equation.

Example: 3(x + 2) = 21. Divide both sides by 3: x + 2 = 7. Subtract 2: x = 5. Check: 3(5 + 2) = 21. ✓

Inverse operations: undo + with −, − with +, × with ÷ and ÷ with ×, always on both sides.

See three worked examples

Solve 4(x − 3) = 28.
  1. Divide both sides by 4: x − 3 = 7.
  2. Add 3 to both sides: x = 10.
  3. Check: 4(10 − 3) = 4(7) = 28. ✓

Answer: x = 10

Solve 5x − 2(x + 4) = 13.
  1. Expand: 5x − 2x − 8 = 13.
  2. Collect: 3x − 8 = 13.
  3. Add 8: 3x = 21. Divide by 3: x = 7.

Answer: x = 7

Solve −2(3 − x) = 10.
  1. Expand: −6 + 2x = 10.
  2. Add 6: 2x = 16.
  3. Divide by 2: x = 8.

Answer: x = 8
