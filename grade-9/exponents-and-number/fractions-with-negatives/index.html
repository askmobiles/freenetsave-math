Adding fractions with negatives

To add fractions, use a common denominator. Then add the numerators using the integer sign rules.

1 Learn2 See3 Try4 Play5 Test6 Challenge

Learn

A negative fraction can be written three ways: −3/4 = (−3)/4 = 3/(−4). It is usually easiest to keep the minus sign on the top.

Steps

  1. Find the lowest common denominator (LCD).
  2. Rewrite each fraction over the LCD.
  3. Add or subtract the numerators, using integer rules.
  4. Simplify.

Example: −1/2 + 3/4. LCD 4: −2/4 + 3/4 = 1/4.

Watch subtraction: 2/3 − (−1/6) = 2/3 + 1/6 = 4/6 + 1/6 = 5/6.

See three worked examples

−2/3 + 1/4
  1. LCD 12: −8/12 + 3/12.
  2. −8 + 3 = −5.

Answer: −5/12

−1/5 − 3/10
  1. LCD 10: −2/10 − 3/10.
  2. −2 − 3 = −5, so −5/10.
  3. Simplify.

Answer: −1/2

3/4 − (−1/2)
  1. Subtracting a negative is adding: 3/4 + 1/2.
  2. LCD 4: 3/4 + 2/4 = 5/4.

Answer: 5/4 or 1 1/4
