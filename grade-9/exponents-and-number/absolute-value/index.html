Absolute value

The absolute value of a number is its distance from zero, so it is never negative.

1 Learn2 See3 Try4 Play5 Test6 Challenge

Learn

The absolute value of a number, written |x|, is how far it is from 0 on a number line. Distance has no direction, so absolute value is never negative.

  • |7| = 7 and |−7| = 7.
  • |0| = 0.

Bars work like brackets

Work out what is inside the bars first, then take the absolute value: |3 − 10| = |−7| = 7. Note that |3 − 10| is not the same as |3| − |10| = −7.

Distance between two numbers

The distance between a and b on a number line is |a − b|. The distance between −4 and 9 is |−4 − 9| = 13.

Remember: absolute value removes the sign of the final result inside the bars, not of each number along the way.

See three worked examples

|−12| + |4|
  1. |−12| = 12 and |4| = 4.
  2. 12 + 4 = 16.

Answer: 16

|5 − 13|
  1. Inside first: 5 − 13 = −8.
  2. |−8| = 8.

Answer: 8

How far apart are −15 m and 22 m?
  1. Distance = |−15 − 22| = |−37|.

Answer: 37 m
