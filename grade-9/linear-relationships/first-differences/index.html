First differences and tables

If the y-values in a table go up or down by the same amount each step, the relation is linear.

1 Learn2 See3 Try4 Play5 Test6 Challenge

Learn

In a table where x goes up by 1 each time, the first differences are the amounts y changes from one row to the next.

xyfirst difference
15
28+3
311+3
414+3
  • If all the first differences are equal, the relation is linear, and the difference is the slope.
  • If they are not equal, it is non-linear (for example y = x² has differences 3, 5, 7, …).

Finding the rule

The slope is 3. Work backwards one step from x = 1 to x = 0: 5 − 3 = 2. So y = 3x + 2.

Watch the x-steps: if x goes up by 2 each row, divide the difference by 2 to get the slope.

See three worked examples

x: 1, 2, 3, 4 and y: 7, 4, 1, −2. Is it linear? Find the rule.
  1. Differences: −3, −3, −3. Equal, so linear with slope −3.
  2. At x = 0: y = 7 + 3 = 10.

Answer: y = −3x + 10

x: 1, 2, 3, 4 and y: 1, 4, 9, 16. Is it linear?
  1. Differences: 3, 5, 7.
  2. Not equal.

Answer: not linear (it is y = x²)

Using y: 12, 17, 22, 27 for x = 1 to 4, find y when x = 10.
  1. Slope is 5; at x = 0, y = 7. Rule: y = 5x + 7.
  2. y = 5(10) + 7.

Answer: 57
