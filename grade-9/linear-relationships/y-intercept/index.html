The y-intercept

The y-intercept is where a line crosses the y-axis. In y = mx + b it is the number b.

1 Learn2 See3 Try4 Play5 Test6 Challenge

Learn

Every point on the y-axis has x = 0. So the y-intercept is the value of y when x = 0. In y = mx + b, putting x = 0 gives y = b.

Finding b from the slope and a point

If a line has slope 2 and passes through (3, 7): substitute into y = mx + b. 7 = 2(3) + b, so b = 1. The equation is y = 2x + 1.

Meaning in real life

The y-intercept is often a starting value or a fixed cost. In C = 0.25k + 40 for a rental van, $40 is the cost before you drive any kilometres.

Formula: b = y − mx, using any point (x, y) on the line.

See three worked examples

What is the y-intercept of y = 4x − 9?
  1. It is in the form y = mx + b.
  2. b = −9.

Answer: −9 (the point (0, −9))

A line has slope −3 and passes through (2, 1). Find b.
  1. b = y − mx = 1 − (−3)(2).
  2. b = 1 + 6 = 7.

Answer: b = 7, so y = −3x + 7

Find the y-intercept of the line through (2, 5) and (6, 13).
  1. Slope = (13 − 5) ÷ (6 − 2) = 2.
  2. b = 5 − 2(2) = 1.

Answer: b = 1
