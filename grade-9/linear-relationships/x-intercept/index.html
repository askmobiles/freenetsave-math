The x-intercept

The x-intercept is where a line crosses the x-axis, where y = 0.

1 Learn2 See3 Try4 Play5 Test6 Challenge

Learn

Every point on the x-axis has y = 0. To find the x-intercept, set y = 0 and solve for x.

For y = 2x − 4: 0 = 2x − 4, so 2x = 4 and x = 2. The line crosses the x-axis at (2, 0).

Using intercepts to graph

For an equation like 3x + 2y = 12, the intercepts are quick to find: x = 0 gives y = 6, and y = 0 gives x = 4. Plot (0, 6) and (4, 0) and join them.

Real-life meaning: if V = 400 − 25t is the water left in a tank, the t-intercept (16) is when the tank is empty.

See three worked examples

Find the x-intercept of y = −3x + 9.
  1. Set y = 0: 0 = −3x + 9.
  2. 3x = 9, so x = 3.

Answer: (3, 0)

Find both intercepts of 4x − 5y = 20.
  1. x = 0: −5y = 20, so y = −4.
  2. y = 0: 4x = 20, so x = 5.

Answer: (5, 0) and (0, −4)

A phone battery has B = 100 − 8h percent left after h hours. When is it empty?
  1. Set B = 0: 100 − 8h = 0.
  2. h = 100 ÷ 8 = 12.5.

Answer: after 12.5 hours
