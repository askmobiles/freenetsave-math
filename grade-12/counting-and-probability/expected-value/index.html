Expected value

Expected value = Σ (outcome × probability).

1 Learn2 See3 Try4 Play5 Test6 Challenge

Learn

A game: spin and win $10 with probability 1/4, otherwise win $2.

E = 10 × 1/4 + 2 × 3/4 = 2.50 + 1.50 = $4.00. If you play many times, you average $4 a game.

Is it fair?

If it costs $5 to play, you lose about $1 a game on average. A fair game has expected profit 0.

A die

The expected roll is (1 + 2 + 3 + 4 + 5 + 6) ÷ 6 = 3.5 — not a number you can actually roll!

Insurance and lotteries are designed so the expected value favours the company.
