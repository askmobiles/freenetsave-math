Multiplying a vector by a number

k(a, b) = (ka, kb). It stretches the vector by k, and a negative k reverses it.

1 Learn2 See3 Try4 Play5 Test6 Challenge

Learn

2(3, 1) = (6, 2): same direction, twice as long. −1(3, 1) = (−3, −1): same length, opposite direction.

  • k > 1: longer. 0 < k < 1: shorter. k < 0: reversed.
  • Two vectors are parallel if one is a scalar multiple of the other: (2, 6) = 2(1, 3).

Combining: 2u − 3v = 2(1, 4) − 3(2, 1) = (2, 8) − (6, 3) = (−4, 5).
