Rational functions and asymptotes

Vertical asymptote: where the bottom is zero. Horizontal asymptote: the value f(x) settles at for large x.

1 Learn2 See3 Try4 Play5 Test6 Challenge

Learn

f(x) = (2x + 1) / (x − 3).

dashed red line: x = 3

  • Vertical asymptote: x − 3 = 0, so x = 3. The graph shoots up or down near it.
  • Horizontal asymptote: for huge x, (2x + 1)/(x − 3) ≈ 2x/x = 2. So y = 2.

Rule for horizontal asymptotes

  • Same degree top and bottom: y = (leading coefficient on top) ÷ (leading on bottom).
  • Bottom has higher degree: y = 0.

Holes: if a factor cancels, like (x − 1)/(x − 1)(x + 2), there is a hole at x = 1, not an asymptote.

See three worked examples

f(x) = 5/(x + 2)
  1. Bottom zero at −2; bottom has higher degree.

Answer: x = −2, y = 0

f(x) = (3x − 1)/(x − 4)
  1. x = 4; 3/1.

Answer: x = 4, y = 3

f(x) = (6x + 2)/(2x + 1)
  1. 2x + 1 = 0; 6/2.

Answer: x = −1/2, y = 3
