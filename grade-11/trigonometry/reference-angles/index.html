Reference angles

The reference angle is the acute angle between the terminal arm and the x-axis.

1 Learn2 See3 Try4 Play5 Test6 Challenge

Learn

Every angle has a reference angle between 0° and 90°. It tells you the size of sin and cos; the quadrant tells you the sign.

QuadrantAngle θReference angle
10°–90°θ
290°–180°180° − θ
3180°–270°θ − 180°
4270°–360°360° − θ

220° is in quadrant 3, so its reference angle is 220 − 180 = 40°.

Always measure to the x-axis, never to the y-axis.
