Solving exponential equations

Write both sides as powers of the same base, then set the exponents equal.

1 Learn2 See3 Try4 Play5 Test6 Challenge

Learn

2ˣ = 32. Write 32 as a power of 2: 32 = 2⁵. So 2ˣ = 2⁵ and x = 5.

Different bases

4ˣ = 8. Both are powers of 2: (2²)ˣ = 2³ → 2^(2x) = 2³ → 2x = 3 → x = 3/2.

Powers to recognise

  • 2: 2, 4, 8, 16, 32, 64, 128, 256
  • 3: 3, 9, 27, 81, 243
  • 5: 5, 25, 125, 625

When there is no common base, you need logarithms (next lesson).

See three worked examples

3ˣ = 81
  1. 81 = 3⁴.

Answer: x = 4

9ˣ = 27
  1. 3^(2x) = 3³.
  2. 2x = 3.

Answer: x = 3/2

2^(x + 1) = 16
  1. 16 = 2⁴.
  2. x + 1 = 4.

Answer: x = 3
