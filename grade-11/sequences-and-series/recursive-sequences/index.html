Recursive formulas

A recursive formula gives the first term and a rule to get each term from the previous one.

1 Learn2 See3 Try4 Play5 Test6 Challenge

Learn

t₁ = 4, tₙ = tₙ₋₁ + 3 means "start at 4, then keep adding 3": 4, 7, 10, 13, …

t₁ = 2, tₙ = 3tₙ₋₁ means "start at 2, keep multiplying by 3": 2, 6, 18, 54, …

Famous example

The Fibonacci sequence: t₁ = 1, t₂ = 1, tₙ = tₙ₋₁ + tₙ₋₂. 1, 1, 2, 3, 5, 8, 13, 21, … It shows up in pine cones, sunflowers and shells.

Recursive vs explicit

Recursive: easy to describe, but to find t₁₀₀ you need all 99 before it. Explicit (tₙ = 3n + 1): jump straight to any term.

Savings example: balance next month = balance this month × 1.01 + 50.
