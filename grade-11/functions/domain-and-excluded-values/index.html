Domain and excluded values

You cannot divide by zero, and you cannot take the square root of a negative (in real numbers).

1 Learn2 See3 Try4 Play5 Test6 Challenge

Learn

Fractions

f(x) = 5 / (x − 3). When x = 3 the bottom is 0, so x ≠ 3. Domain: all real numbers except 3.

The graph has a gap (an asymptote) at x = 3.

Square roots

g(x) = √(x − 2) needs x − 2 ≥ 0, so x ≥ 2.

Factor the bottom to find all excluded values: 1/(x² − 9) excludes x = 3 and x = −3.

See three worked examples

f(x) = 7/(x + 4)
  1. x + 4 = 0.

Answer: x ≠ −4

f(x) = √(x + 5)
  1. x + 5 ≥ 0.

Answer: x ≥ −5

f(x) = 1/(x² − x)
  1. x(x − 1) = 0.

Answer: x ≠ 0, 1
