Functions and function notation

A function gives exactly one output for each input. f(3) means "put 3 in for x".

1 Learn2 See3 Try4 Play5 Test6 Challenge

Learn

A function is a rule where every input x has exactly one output y. On a graph, a vertical line never hits it twice (the vertical line test).

f(x) = x² − 2x + 3 is read "f of x". To find f(4), replace every x with 4: 16 − 8 + 3 = 11. So f(4) = 11, and the point (4, 11) is on the graph.

Negatives in brackets

f(−1) = (−1)² − 2(−1) + 3 = 1 + 2 + 3 = 6.

Domain = all allowed inputs. Range = all outputs. Here the range is y ≥ 2.

See three worked examples

f(x) = 3x − 7. f(5)?
  1. 15 − 7.

Answer: 8

g(x) = 2x² + 1. g(−3)?
  1. 2(9) + 1.

Answer: 19

h(x) = x² − x. h(a + 1)?
  1. (a + 1)² − (a + 1).

Answer: a² + a
