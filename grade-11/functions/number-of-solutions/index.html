How many solutions? Using the discriminant

b² − 4ac positive: 2 solutions. Zero: 1 solution. Negative: none.

1 Learn2 See3 Try4 Play5 Test6 Challenge

Learn

Review: for ax² + bx + c = 0, the discriminant D = b² − 4ac.

  • D > 0 → 2 real solutions
  • D = 0 → 1 real solution
  • D < 0 → 0 real solutions

Does a line hit a parabola?

Set them equal. y = x² + 1 and y = 2x: x² − 2x + 1 = 0, D = 4 − 4 = 0. The line touches the parabola once (it is a tangent).

Finding k: for "exactly one solution", set D = 0 and solve.

See three worked examples

x² + 4x + 5 = 0
  1. D = 16 − 20 = −4.

Answer: 0 solutions

2x² − 3x − 2 = 0
  1. D = 9 + 16 = 25.

Answer: 2 solutions

x² + kx + 9 = 0 has one solution, k > 0
  1. k² − 36 = 0.

Answer: k = 6
