Composition: f(g(x))

f(g(x)): do the inside function first, then put its answer into the outside one.

1 Learn2 See3 Try4 Play5 Test6 Challenge

Learn

f(x) = 2x + 1 and g(x) = x². Find f(g(3)).

  1. Inside: g(3) = 9.
  2. Outside: f(9) = 2(9) + 1 = 19.

Order matters: g(f(3)) = g(7) = 49. Not the same!

As a formula

f(g(x)) = 2(x²) + 1 = 2x² + 1. g(f(x)) = (2x + 1)².

Real life: convert dollars to euros (g), then add a fee (f). The order you do them in changes the result.

See three worked examples

f(x) = x − 4, g(x) = 3x. f(g(5))
  1. g(5) = 15.
  2. f(15) = 11.

Answer: 11

Same functions. g(f(5))
  1. f(5) = 1.
  2. g(1) = 3.

Answer: 3

f(x) = x², g(x) = x + 2. f(g(x))
  1. (x + 2)².

Answer: x² + 4x + 4
