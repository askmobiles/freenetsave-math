Solving f(x) = k

f(x) = k asks: which input gives this output? Set the rule equal to k and solve.

1 Learn2 See3 Try4 Play5 Test6 Challenge

Learn

f(x) = 4x − 3. For which x is f(x) = 17?

4x − 3 = 17 → 4x = 20 → x = 5.

On a graph

Draw the horizontal line y = k. Where it crosses the graph are the answers.

For f(x) = x² − 1 = 3, x² = 4, so x = 2 or −2: two answers.

Do not confuse f(3) (put in 3) with f(x) = 3 (find the x that gives 3).

See three worked examples

f(x) = 2x + 9, f(x) = 1
  1. 2x = −8.

Answer: x = −4

f(x) = x² + 5, f(x) = 30
  1. x² = 25.

Answer: x = ±5

f(x) = (x − 1)/3, f(x) = 4
  1. x − 1 = 12.

Answer: x = 13
