Chance as a fraction

Picking from a bag. Grade 7 math.

1 Learn2 See3 Try4 Play5 Test

Learn the key ideas

  1. Count how many you want.
  2. Count how many there are in all.
  3. Chance = wanted over total. Simplify if you can.

Read the worked examples next. Then try the practice questions, which show the steps after every answer.
