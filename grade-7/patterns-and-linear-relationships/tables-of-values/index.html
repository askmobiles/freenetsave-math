Tables of values

A rule turns each x into a y. List them in a table and the pattern is easy to see.

1 Learn2 See3 Try4 Play5 Test6 Challenge

Learn

The rule y = 2x + 1: double x, then add 1.

x01234
y13579

Each time x goes up by 1, y goes up by 2. Plotted, the points make a straight line.

Multiply first, then add. For y = 4x + 6 and x = 3: 4 × 3 = 12, then 12 + 6 = 18.

See three worked examples

y = 4x + 6. Find y when x = 3.
  1. 4 × 3 = 12.
  2. 12 + 6.

Answer: 18

y = 6x + 1. Find y when x = 5.
  1. 6 × 5 = 30.
  2. 30 + 1.

Answer: 31

y = 2x − 3. Find y when x = 0.
  1. 2 × 0 = 0.
  2. 0 − 3.

Answer: −3
