Adding fractions with different denominators

You can only add pieces of the same size. Cut both fractions into equal pieces first.

1 Learn2 See3 Try4 Play5 Test6 Challenge

Learn

How much is 1/3 + 1/4? Thirds and quarters are different sizes, so cut both into twelfths.

The steps

  1. Find a number both bottoms divide into (a common denominator). For 3 and 4, use 12.
  2. Change each fraction: multiply top and bottom by the same number.
  3. Add the tops. Keep the bottom. Simplify if you can.

Never add the bottoms. 1/3 + 1/4 is not 2/7. Two pieces of different sizes can't be counted as sevenths.

See three worked examples

1/3 + 1/4
  1. Common denominator 12.
  2. 1/3 = 4/12 and 1/4 = 3/12.
  3. 4/12 + 3/12.

Answer: 7/12

2/3 + 1/5
  1. Common denominator 15.
  2. 2/3 = 10/15 and 1/5 = 3/15.
  3. 10/15 + 3/15.

Answer: 13/15

3/4 + 3/5
  1. Common denominator 20.
  2. 3/4 = 15/20 and 3/5 = 12/20.
  3. 15/20 + 12/20 = 27/20, which is 1 7/20.

Answer: 27/20
