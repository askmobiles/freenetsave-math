Adding and subtracting fractions

You can only add or subtract fractions when the pieces are the same size. A common denominator makes them the same size.

1 Learn2 See3 Try4 Play5 Test6 Challenge

Learn

The bottom number of a fraction, the denominator, tells you the size of the pieces. The top number, the numerator, tells you how many pieces you have.

Same denominator

The pieces are already the same size, so add or subtract the tops and keep the bottom: 2/7 + 3/7 = 5/7.

Different denominators

First rename the fractions so they have the same denominator. Look for the smallest number both bottoms divide into.

In the picture, 1/2 is renamed as 2/4. Now both fractions are in quarters, and 2 quarters plus 1 quarter is 3 quarters.

  1. Find a common denominator.
  2. Rename each fraction. Whatever you multiply the bottom by, multiply the top by the same number.
  3. Add or subtract the tops. Keep the bottom.
  4. Simplify if the top and bottom share a factor.

Never add the bottoms. 1/2 + 1/4 is not 2/6. Two sixths is less than one half, so that answer cannot be right.

See three worked examples

2/3 + 1/4
  1. Both 3 and 4 divide into 12, so use twelfths.
  2. Rename: 2/3 = 8/12 and 1/4 = 3/12.
  3. Add the tops: 8 + 3 = 11.

Answer: 11/12

3/4 − 2/5
  1. Both 4 and 5 divide into 20, so use twentieths.
  2. Rename: 3/4 = 15/20 and 2/5 = 8/20.
  3. Subtract the tops: 15 − 8 = 7.

Answer: 7/20

5/6 − 1/2
  1. 6 is already a multiple of 2, so use sixths.
  2. Rename: 1/2 = 3/6. Now 5/6 − 3/6 = 2/6.
  3. Simplify: divide top and bottom by 2.

Answer: 1/3
