Finding the rule from a table

x1234
y591317

y goes up by 4 each time x goes up by 1, so the rule starts y = 4x. When x = 1, 4x = 4, but y = 5, so add 1: y = 4x + 1.

The jump in y is the slope, as long as x goes up by 1 each time.

See three worked examples

y = 3x − 2. Find y when x = 4.
  1. 3 × 4 = 12.
  2. 12 − 2.

Answer: 10

Fill in y = 2x + 3 for x = 0, 1 and 2.
  1. x = 0: 0 + 3 = 3.
  2. x = 1: 2 + 3 = 5.
  3. x = 2: 4 + 3 = 7.

Answer: 3, 5, 7

A table has x = 1, 2, 3, 4 and y = 5, 9, 13, 17. Find the rule.
  1. y goes up by 4 each time, so start with 4x.
  2. 4 × 1 = 4, and y is 5, so add 1.

Answer: y = 4x + 1
