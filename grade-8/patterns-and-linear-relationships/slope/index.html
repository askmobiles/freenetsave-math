Slope: rise over run

Slope tells you how steep a line is: how far it goes up (rise) for how far it goes across (run).

1 Learn2 See3 Try4 Play5 Test6 Challenge

Learn

Take the points (1, 2) and (4, 8). Going from the first to the second, the line goes 3 across and 6 up.

Slope = rise ÷ run = 6 ÷ 3 = 2.

The steps

  1. Rise = second y − first y.
  2. Run = second x − first x.
  3. Slope = rise ÷ run.

Negative and zero slopes

From (0, 5) to (2, 1): rise = 1 − 5 = −4 and run = 2. Slope = −2, so the line goes down. A flat line has a rise of 0, so its slope is 0.

Keep the same order. If you start rise with the second point, start run with the second point too.

See three worked examples

Find the slope of the line through (1, 2) and (4, 8).
  1. Rise: 8 − 2 = 6.
  2. Run: 4 − 1 = 3.
  3. 6 ÷ 3.

Answer: 2

Find the slope of the line through (0, 5) and (2, 1).
  1. Rise: 1 − 5 = −4.
  2. Run: 2 − 0 = 2.
  3. −4 ÷ 2.

Answer: −2

Find the slope of the line through (−2, 1) and (6, 5).
  1. Rise: 5 − 1 = 4.
  2. Run: 6 − (−2) = 8.
  3. 4 ÷ 8, in simplest form.

Answer: 1/2
