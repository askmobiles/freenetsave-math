Number patterns and the nth term

Find the jump between terms and you can write a rule. The rule finds any term, even the 100th, without counting.

1 Learn2 See3 Try4 Play5 Test6 Challenge

Learn

Each picture in this pattern adds 2 squares.

The numbers are 3, 5, 7, … The jump is +2, so the rule starts with 2n. 2n gives 2, 4, 6, which is 1 less each time, so the rule is 2n + 1.

Now any term is easy: the 50th term has 2 × 50 + 1 = 101 squares.

The steps

  1. Find the jump. That is the number in front of n.
  2. Compare jump × n with the first term to find what to add or take away.
  3. Check the rule on the second term.

If the pattern goes down, the jump is negative. 40, 36, 32, … has a jump of −4, so the rule is 44 − 4n.

Always check. For 5, 8, 11, the rule 3n + 2 gives 3 × 1 + 2 = 5 and 3 × 2 + 2 = 8. Both match.

See three worked examples

What comes next: 5, 8, 11, 14, …?
  1. The jump is +3 every time.
  2. 14 + 3.

Answer: 17

Find the 20th term of 5, 8, 11, 14, …
  1. Jump +3, so the rule starts 3n.
  2. 3 × 1 = 3, but the first term is 5, so add 2: rule 3n + 2.
  3. 3 × 20 + 2.

Answer: 62

Find the 10th term of 40, 36, 32, 28, …
  1. Jump −4, so the rule starts −4n.
  2. −4 × 1 = −4, and the first term is 40, so add 44: rule 44 − 4n.
  3. 44 − 4 × 10.

Answer: 4
