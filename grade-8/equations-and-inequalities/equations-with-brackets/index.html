Equations with brackets

With brackets, you can divide by the number outside first, or expand the brackets first. Both give the same answer.

1 Learn2 See3 Try4 Play5 Test6 Challenge

Learn

Take 3(x + 2) = 21.

Way 1: divide first

Divide both sides by 3: x + 2 = 7. Take 2 from both sides: x = 5.

Way 2: expand first

3(x + 2) = 3x + 6, so 3x + 6 = 21. Take 6: 3x = 15. Divide by 3: x = 5.

When to expand

If x is on both sides, such as 2(x + 5) = x + 17, expand first: 2x + 10 = x + 17. Take x from both sides: x + 10 = 17, so x = 7.

Dividing first is quicker when the right side divides evenly by the number outside. Otherwise, expand first.

See three worked examples

Solve 3(x + 2) = 21.
  1. Divide both sides by 3: x + 2 = 7.
  2. Take 2 from both sides.

Answer: x = 5

Solve 4(2x − 1) = 28.
  1. Divide both sides by 4: 2x − 1 = 7.
  2. Add 1: 2x = 8.
  3. Divide by 2.

Answer: x = 4

Solve 2(x + 5) = x + 17.
  1. Expand: 2x + 10 = x + 17.
  2. Take x from both sides: x + 10 = 17.
  3. Take 10 from both sides.

Answer: x = 7
