The cosine law

The cosine law is Pythagoras with a correction for angles that are not 90°.

1 Learn2 See3 Try4 Play5 Test6 Challenge

Learn

c² = a² + b² − 2ab cos C

Use it when you know two sides and the angle between them (SAS), or all three sides (SSS) and want an angle.

a = 5, b = 8, C = 60° (cos 60° = 0.5): c² = 25 + 64 − 2(5)(8)(0.5) = 89 − 40 = 49 → c = 7.

Link to Pythagoras

If C = 90°, cos 90° = 0, and the formula becomes c² = a² + b².

Order of operations: do 2ab cos C as one number, then subtract.
