Solving quadratic equations by factoring

Factor, then set each bracket equal to zero.

1 Learn2 See3 Try4 Play5 Test6 Challenge

Learn

A quadratic equation has an x² term: x² − 5x + 6 = 0.

The zero product rule

If A × B = 0, then A = 0 or B = 0. So factor first:

x² − 5x + 6 = 0 → (x − 2)(x − 3) = 0 → x − 2 = 0 or x − 3 = 0 → x = 2 or x = 3.

These answers are called the roots. On a graph they are where the parabola crosses the x-axis.

Get 0 on one side first. x² = 4x becomes x² − 4x = 0 → x(x − 4) = 0 → x = 0 or 4. Never divide by x — you would lose x = 0.

See three worked examples

x² + 7x + 10 = 0
  1. (x + 2)(x + 5) = 0.

Answer: x = −2 or −5

x² − 16 = 0
  1. (x − 4)(x + 4) = 0.

Answer: x = 4 or −4

x² + 3x = 18
  1. x² + 3x − 18 = 0.
  2. (x + 6)(x − 3) = 0.

Answer: x = −6 or 3
