Completing the square

Half of b gives p. Then adjust the constant.

Learn

Completing the square turns standard form into vertex form.

Steps for x² + 6x + 5

  1. Half of 6 is 3, so the square is (x + 3)² = x² + 6x + 9.
  2. We only have 5, not 9, so subtract 4: x² + 6x + 5 = (x + 3)² − 4.

Vertex (−3, −4).

x² + bx + c = (x + b/2)² + (c − (b/2)²)

If a ≠ 1, factor a out of the x terms first: 2x² + 12x + 1 = 2(x² + 6x) + 1 = 2[(x + 3)² − 9] + 1 = 2(x + 3)² − 17.

See three worked examples

x² + 10x + 30
  1. Half of 10 is 5; 5² = 25.
  2. 30 − 25 = 5.

Answer: (x + 5)² + 5

x² − 8x + 3
  1. Half of −8 is −4; 16.
  2. 3 − 16 = −13.

Answer: (x − 4)² − 13

Minimum of y = x² + 4x + 11
  1. (x + 2)² + 7.

Answer: 7, at x = −2
