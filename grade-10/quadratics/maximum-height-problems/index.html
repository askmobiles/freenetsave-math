Quadratic models: maximum height

The vertex of the height parabola gives the time and the maximum height.

1 Learn2 See3 Try4 Play5 Test6 Challenge

Learn

A ball thrown straight up at v metres per second has height about h = −5t² + vt (t in seconds). The −5 comes from gravity.

Time to the top

t = −b ÷ 2a = −20 ÷ (−10) = 2 s.

Maximum height

h = −5(2)² + 20(2) = −20 + 40 = 20 m.

Landing time

h = 0: −5t(t − 4) = 0, so t = 0 (start) or t = 4 s. The top is always halfway to landing.

Same idea for money: a profit P = −2x² + 40x is greatest at x = 10.

See three worked examples

h = −5t² + 30t. When is it highest?
  1. t = −30 ÷ (−10).

Answer: 3 s

h = −5t² + 30t. Maximum height?
  1. h = −45 + 90.

Answer: 45 m

h = −5t² + 10t + 15. When does it land?
  1. −5(t² − 2t − 3) = 0.
  2. −5(t − 3)(t + 1) = 0.

Answer: t = 3 s
