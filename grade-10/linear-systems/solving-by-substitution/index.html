Solving systems by substitution

If one equation says what y equals, put that into the other equation.

1 Learn2 See3 Try4 Play5 Test6 Challenge

Learn

y = 2x + 1
3x + y = 16

The first equation tells us y is the same as 2x + 1. Replace y in the second equation:

3x + (2x + 1) = 16 → 5x + 1 = 16 → 5x = 15 → x = 3. Then y = 2(3) + 1 = 7. Solution (3, 7).

When to use it

Substitution is best when one variable is already alone, or has no number in front (like x + 2y = 9 → x = 9 − 2y).

Use brackets when you substitute, especially with a minus sign: 4x − (2x + 1) = 4x − 2x − 1.

See three worked examples

y = x + 4, 2x + y = 13
  1. 2x + x + 4 = 13.
  2. 3x = 9, x = 3, y = 7.

Answer: (3, 7)

x = 2y, x + y = 18
  1. 2y + y = 18, y = 6.
  2. x = 12.

Answer: (12, 6)

y = 3x − 2, 4x − y = 5
  1. 4x − (3x − 2) = 5.
  2. x + 2 = 5, x = 3, y = 7.

Answer: (3, 7)
