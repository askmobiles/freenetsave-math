Point of intersection

Two lines meet at one point, unless they are parallel or are the same line.

1 Learn2 See3 Try4 Play5 Test6 Challenge

Learn

The point of intersection is the solution of the system: it lies on both lines.

Without graphing

If both equations start "y =", set them equal: x + 1 = −2x + 7 → 3x = 6 → x = 2. Then y = 3.

How many solutions?

  • Different slopes → one solution.
  • Same slope, different intercept → parallel, no solution.
  • Same slope and intercept → same line, infinitely many.

Graphs give a picture; algebra gives an exact answer when the point is not on whole numbers.

See three worked examples

y = 2x − 1 and y = x + 3
  1. 2x − 1 = x + 3, x = 4.
  2. y = 7.

Answer: (4, 7)

y = 3x + 2 and y = 3x − 5
  1. Same slope, different intercepts.

Answer: no solution (parallel)

y = −x + 6 and y = 2x
  1. −x + 6 = 2x, x = 2.
  2. y = 4.

Answer: (2, 4)
