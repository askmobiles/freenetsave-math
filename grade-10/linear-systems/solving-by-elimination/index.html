Solving systems by elimination

Add or subtract the two equations so that one variable disappears.

1 Learn2 See3 Try4 Play5 Test6 Challenge

Learn

A linear system is two equations with the same two unknowns. The solution is the (x, y) that makes both true.

x + y = 10
x − y = 4

Add the equations: the +y and −y cancel. 2x = 14, so x = 7. Put x = 7 back into x + y = 10: y = 3. Solution (7, 3).

When nothing cancels yet

Multiply one (or both) equations first. For 2x + 3y = 12 and x + y = 5, multiply the second by 2: 2x + 2y = 10. Now subtract: y = 2, then x = 3.

Check: put your answer into both original equations.

See three worked examples

x + y = 9, x − y = 3
  1. Add: 2x = 12, x = 6.
  2. y = 9 − 6 = 3.

Answer: (6, 3)

3x + 2y = 16, x + 2y = 8
  1. Subtract: 2x = 8, x = 4.
  2. 4 + 2y = 8, y = 2.

Answer: (4, 2)

2x + y = 7, 3x − 2y = 0
  1. Double the first: 4x + 2y = 14.
  2. Add: 7x = 14, x = 2. Then y = 3.

Answer: (2, 3)
