Word problems with two unknowns

Name the two unknowns, write two equations from the two facts, then solve.

1 Learn2 See3 Try4 Play5 Test6 Challenge

Learn

Steps

  1. Let statements: "Let x = the bigger number, y = the smaller number."
  2. Write one equation for each fact.
  3. Solve the system.
  4. Answer in a sentence and check.

"Two numbers add to 40 and differ by 6."
x + y = 40 and x − y = 6. Add: 2x = 46, x = 23, y = 17.

Tickets

"Adult tickets cost $12, child tickets $5. 30 tickets were sold for $248." Let a = adults, c = children: a + c = 30 and 12a + 5c = 248. Multiply the first by 5: 5a + 5c = 150. Subtract: 7a = 98, a = 14, c = 16.

Shortcut for sum and difference: bigger = (sum + difference) ÷ 2, smaller = (sum − difference) ÷ 2.

See three worked examples

Two numbers add to 50 and differ by 14. Find the bigger.
  1. (50 + 14) ÷ 2.

Answer: 32

You have 20 coins, all dimes and quarters, worth $3.80. How many quarters?
  1. d + q = 20, 10d + 25q = 380.
  2. 10d + 10q = 200; subtract: 15q = 180.

Answer: 12 quarters

A rectangle's perimeter is 34 cm and its length is 5 cm more than its width. Find the length.
  1. 2L + 2W = 34 → L + W = 17. L − W = 5.
  2. L = (17 + 5) ÷ 2.

Answer: 11 cm
