Finding both variables

A system is only solved when you know both x and y.

1 Learn2 See3 Try4 Play5 Test6 Challenge

Learn

After eliminating, you only know one variable. Back-substitute to get the other.

3x + y = 17
x + y = 7

Subtract: 2x = 10, x = 5. Put x = 5 into x + y = 7: y = 2. Solution (5, 2).

Choose the easy equation

Put the value into whichever equation is simplest. Then check in the other one: 3(5) + 2 = 17 ✓.

What the answer means

The solution is the point where the two lines cross on a graph.

Write the answer as a point, like (5, 2).

See three worked examples

4x + y = 14, x + y = 5
  1. Subtract: 3x = 9, x = 3.
  2. y = 5 − 3 = 2.

Answer: (3, 2)

2x + y = 1, x + y = −1
  1. Subtract: x = 2.
  2. y = −1 − 2 = −3.

Answer: (2, −3)

5x + y = 20, 2x + y = 8
  1. Subtract: 3x = 12, x = 4.
  2. y = 8 − 8 = 0.

Answer: (4, 0)
